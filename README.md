## Изворни код и покретање система
Изворни код је развијен у оквиру завршног рада *ПРОЈЕКТОВАЊЕ И ИМПЛЕМЕНТАЦИЈА EVENT-DRIVEN АРХИТЕКТУРЕ ЗА ПОУЗДАНУ ОБРАДУ ДОГАЂАЈА У ДИСТРИБУИРАНИМ СИСТЕМИМА*. 

Имплементација представља демонстрацију пројектоване архитектуре у раду. Постављена су три одговарајућа сервиса која комуницирају Kafka системом. Сваки сервис има сопствену базу података. Имплементација такође обухвата механизме Transactional Outbox и идемпотентности потрошача, као и употребу потрошачких група и партиција. Сервис за обраду скалиран је на три инстанце које деле обраду порука са једне теме.

Имплементација је остварена користећи: Typescript, NestJS, Docker, PostgreSQL, Kafka, Kafka UI.
Цео систем се покреће користећи Docker. На тај начин, сви сервиси и компоненте се одвајају у различите контејнере и симулирају дистрибуиран систем.

### Преузимање и покретање

За покретање система неопходно је имати инсталиране следеће алате:
- Docker и Docker Compose (На Windows оперативном систему потребан је Docker Desktop)
- Git

Потребно је преузети GitHub репозиторијум:  
 ```git clone https://github.com/Nemanja-Stojanovic-Fakultet/event-driven-thesis```

Након тога, из корена директоријума потребно је покренути:  
  ```docker compose up -d --build```

Овом командом се припремају и покрећу сви сервиси и компоненте неопходне за рад система. Креирају се одговарајуће теме, партиције и табеле.

### Тестирање система

Након успешног покретања, може се у претраживачу отворити Swagger чија је подразумевана локација: http://localhost:3000/api_doc. Изглед Swagger корисничког интерфејса приказан је на слици А.2.

![Swagger](https://i.imgur.com/eVbgqGX.png)


Уз Kafka систем додат је и Kafka UI чија је подразумевана локација: http://localhost:8080 
Postgres базом података може се приступити на локацији: http://localhost:5432 са корисничким именом и лозинком postgres. За приступ је потребно користити одговарајући алат, на пример pgAdmin 4.
